# Como baixar

Clone o código no github com
```bash
git clone "https://github.com/themooproject/MooAI"
```
entre na pasta criada com o cd
```bash
cd MooAI/
```
após isso crie um venv
```bash
python3 -m venv venv
```
entre no venv
```bash
source venv/bin/activate
```
instale as dependências
```bash
pip install flask
```
agora baixe o ollama com o script oficial e com ele baixe o modelo ```llama3.2:3b```
